## 📝 실습 개요
본 프로젝트는 임베디드 시스템의 가장 기초적인 인터페이스인 **GPIO(General Purpose Input/Output)** 핀을 활용하여, 외부 하드웨어(LED, 스위치)와 소프트웨어 로직이 상호작용하는 방식을 다룹니다.

- **출력 제어:** 상태(ON/OFF)의 시각적 피드백 구현
- **입력 제어:** 사용자의 물리적 명령(버튼 클릭) 감지 및 조건부 동작 수행
- **소프트웨어 처리:** 상태 변화 감지, 시리얼 통신 디버깅, 소프트웨어 디바운싱(Debouncing) 적용

## 🛠 개발 환경
- **Language:** C++ (Arduino Framework)
- **Board:** Arduino Uno
- **Simulator:** [Wokwi](https://wokwi.com) / Tinkercad
- **IDE:** Arduino IDE

## 📂 프로젝트 목록

### 1. LED 점멸 제어 (LED Blink)
아두이노의 디지털 핀을 출력(OUTPUT) 모드로 설정하고, 시간에 따라 주기적으로 디지털 신호를 출력하는 기본 실습입니다.

* **핵심 학습:**
  * `pinMode()`, `digitalWrite()`를 통한 전압 제어 (5V/0V)
  * `delay()` 함수를 활용한 블로킹 방식의 시간 흐름 제어
  * 전류 제한 저항(220Ω~330Ω)의 필요성 이해
* **실행 결과:** 
  * LED가 1초 간격으로 점멸
  * 시리얼 모니터에 현재 상태(`LED State: ON / OFF`) 출력

### 2. 버튼 입력 기반 LED 제어 (Button Controlled LED)
물리 버튼의 디지털 입력 신호를 감지하고, 해당 신호에 따라 출력(LED)을 동적으로 제어하는 실습입니다.

* **핵심 학습:**
  * `digitalRead()`를 통한 신호 감지
  * 플로팅(Floating) 현상 방지를 위한 아두이노 내부 풀업 저항(`INPUT_PULLUP`) 활용
  * 상태 변화 감지(Edge Trigger) 로직 설계
  * 기계적 떨림(Chattering) 현상을 해결하기 위한 소프트웨어 디바운싱(Debouncing) 처리
* **실행 결과:** 
  * 버튼을 누르고 있는 동안 LED 점등, 손을 떼면 소등
  * 상태가 변할 때만 시리얼 모니터에 상태 값(`Button pressed` / `Button released`) 출력

## 🚀 실행 방법

**1. 시뮬레이터(Wokwi/Tinkercad) 사용 시**
1. 코드를 복사하여 시뮬레이터 코드 편집창(`sketch.ino`)에 붙여넣습니다.
2. 회로도에 맞게 LED, 저항, 푸시버튼을 배치하고 배선합니다.
3. 시뮬레이션을 시작(▶)하여 동작과 시리얼 모니터 로그를 확인합니다.

**2. 실제 아두이노 보드 사용 시**
1. 아두이노 보드를 PC와 연결하고 Arduino IDE를 실행합니다.
2. 각 실습의 코드를 작성한 후, `툴 > 보드`와 `포트`를 올바르게 설정합니다.
3. 업로드 버튼(→)을 눌러 코드를 보드에 기록합니다.
4. `우측 상단 돋보기 아이콘(시리얼 모니터)`을 클릭하고 보드레이트를 `9600`으로 설정하여 로그를 확인합니다.
